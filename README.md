# 🏦 ZenVault
### **Secure Backend Banking System**

> [!IMPORTANT]
> **Status:** This project is currently **Under Active Development**. I am focusing on building a robust, production-ready banking architecture.

**ZenVault** is a security-focused backend system built with Spring Boot. It handles core banking operations like JWT authentication, account lifecycle management, and real-time transactions with strict data integrity.

---

## 🛠️ **Tech Stack**

* **Backend:** Java 17+, Spring Boot, Spring Data JPA
* **Security:** Spring Security, JWT (JSON Web Tokens)
* **Database:** MySQL
* **DevTools:** Docker, Postman, Git, Maven

---

## 🚀 **Key Features**

* **Secure Auth:** Registration and login using **JWT** with password encryption (**BCrypt**).
* **Account Management:** Support for **multiple accounts** per user.
* **Transaction Engine:** **Atomic transfers** with validation.
* **Input Validation:** Global exception handling.
